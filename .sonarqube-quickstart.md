# 🚀 SonarCloud Quick Start

## 5-Minute Setup

### 1️⃣ Sign Up (1 min)
→ Go to https://sonarcloud.io
→ Click "Sign up with GitHub"
→ Authorize SonarCloud

### 2️⃣ Create Organization (1 min)
→ Organization key: `shehanfdoking` (or your GitHub username)
→ Choose "Free plan"

### 3️⃣ Import Project (1 min)
→ Click "Analyze new project"
→ Select `devops-project`
→ Click "Set Up" → "With GitHub Actions"

### 4️⃣ Generate Token (1 min)
→ My Account → Security → Generate Tokens
→ Name: `github-actions-devops-project`
→ Type: User Token
→ Click Generate → **COPY TOKEN**

### 5️⃣ Add to GitHub (1 min)
→ Go to: https://github.com/ShehanFdoking/devops-project/settings/secrets/actions
→ Click "New repository secret"
→ Name: `SONAR_TOKEN`
→ Value: [paste your token]
→ Click "Add secret"

### ✅ Done!
Next push will trigger SonarCloud analysis automatically!

## Run Locally (Optional)

```bash
# Set your token
export SONAR_TOKEN=your_token_here

# Run analysis
mvn clean verify sonar:sonar
```

## Quality Gate

Your build will **fail** if:
- ❌ New bugs introduced
- ❌ Security vulnerabilities found
- ❌ Coverage below threshold
- ❌ Too many code smells

This keeps your code quality high! 🎯
