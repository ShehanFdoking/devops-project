# 🚀 AWS ECR Quick Start (10 Minutes)

## Step 1: Install AWS CLI (2 min)

**Windows:**
```powershell
# Download from: https://awscli.amazonaws.com/AWSCLIV2.msi
# Or via Chocolatey:
choco install awscli -y

# Verify
aws --version
```

## Step 2: Create AWS Account (3 min)

1. Go to https://aws.amazon.com
2. Click "Create an AWS Account"
3. Follow signup (requires credit card, but we'll use free tier)

## Step 3: Create IAM User (2 min)

1. Login to AWS Console: https://console.aws.amazon.com
2. Go to IAM → Users → "Add users"
3. Username: `github-actions-ecr`
4. Access type: **Programmatic access** ✅
5. Permissions: Attach `AmazonEC2ContainerRegistryPowerUser` policy
6. **SAVE** Access Key ID and Secret Access Key

## Step 4: Configure AWS CLI (1 min)

```bash
aws configure

# Enter:
# AWS Access Key ID: [your-key]
# AWS Secret Access Key: [your-secret]
# Default region: us-east-1
# Default output format: json
```

## Step 5: Create ECR Repository (1 min)

```bash
aws ecr create-repository \
    --repository-name devops-springboot-app \
    --region us-east-1 \
    --image-scanning-configuration scanOnPush=true
```

**Save the repository URI from output!**

## Step 6: Add GitHub Secrets (1 min)

Go to: https://github.com/ShehanFdoking/devops-project/settings/secrets/actions

Add these secrets:
- `AWS_ACCESS_KEY_ID` = your access key
- `AWS_SECRET_ACCESS_KEY` = your secret key
- `AWS_REGION` = us-east-1
- `ECR_REPOSITORY` = devops-springboot-app

## ✅ Done!

Next push will automatically upload to ECR!

## Quick Commands

### Push Manually (Local)
```powershell
# Windows
.\scripts\push-to-ecr.ps1 -Version "1.0"

# Linux/Mac
./scripts/push-to-ecr.sh 1.0
```

### View Images
```bash
aws ecr list-images --repository-name devops-springboot-app
```

### Pull Image
```bash
# Login first
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin {account-id}.dkr.ecr.us-east-1.amazonaws.com

# Pull
docker pull {account-id}.dkr.ecr.us-east-1.amazonaws.com/devops-springboot-app:latest
```

### View in Console
https://console.aws.amazon.com/ecr
