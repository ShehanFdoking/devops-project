# 🚀 AWS EKS Quick Start (30 Minutes)

## Prerequisites ✅

- [x] AWS CLI configured
- [x] kubectl installed
- [ ] eksctl installed
- [ ] IAM permissions for EKS

## Step 1: Install eksctl (2 min)

```powershell
choco install eksctl -y

# Verify
eksctl version
```

## Step 2: Add IAM Permissions (3 min)

Go to: https://console.aws.amazon.com/iam/home#/users/shehan

Add policies:
- `AmazonEKSClusterPolicy`
- `AmazonEKSWorkerNodePolicy`
- `AmazonEKS_CNI_Policy`
- Or `AdministratorAccess` for learning

## Step 3: Create EKS Cluster (15-20 min)

```bash
eksctl create cluster -f k8s/eks/cluster-config.yaml
```

This creates:
- EKS control plane
- 2x t3.medium worker nodes
- VPC with subnets
- IAM roles
- Add-ons (VPC CNI, CoreDNS, kube-proxy)

**Cost:** ~$140/month (~$0.20/hour)

## Step 4: Verify Cluster (1 min)

```bash
# Check nodes
kubectl get nodes

# Check all resources
kubectl get all --all-namespaces
```

## Step 5: Deploy Application (2 min)

```powershell
.\scripts\deploy-to-eks.ps1
```

Or manually:
```bash
kubectl apply -f k8s/eks/deployment.yaml
```

## Step 6: Get Application URL (2 min)

```bash
kubectl get service devops-springboot-app-service

# Get URL
export LB_URL=$(kubectl get service devops-springboot-app-service -o jsonpath='{.status.loadBalancer.ingress[0].hostname}')

# Test (wait 2-3 min for LB to be ready)
curl http://$LB_URL/api/hello
```

## ✅ Done!

Your app is now running on production Kubernetes!

---

## Quick Commands

```bash
# View pods
kubectl get pods

# View logs
kubectl logs -l app=devops-springboot-app --tail=50

# Scale
kubectl scale deployment devops-springboot-app --replicas=5

# Update image
kubectl set image deployment/devops-springboot-app \
  devops-springboot-app=852093845150.dkr.ecr.eu-north-1.amazonaws.com/devops-springboot-app:v2
```

---

## Cleanup (To Avoid Charges)

```bash
# Delete application
kubectl delete -f k8s/eks/deployment.yaml

# Delete cluster (takes 10-15 min)
eksctl delete cluster --name devops-cluster --region eu-north-1
```
